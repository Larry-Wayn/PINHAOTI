# 拼好题

用 2007—2025 年考研数学一真题组装个人复习卷。试卷和题号索引已放在程序文件夹内，日常使用时只需输入题号。

本目录是源码版；可用 `.command` 直接运行。另行提供的 macOS 应用压缩包包含可双击的 `.app`。

## 打开 macOS 应用

解压“拼好题 macOS 应用”后，双击 `拼好题.app`。浏览器会自动打开组卷页面；用完后点页面底部的“结束程序”。应用内已包含 Python、排版组件和这 19 份真题，日常使用不需安装 Python 或联网。

这份应用针对制作时的 Apple Silicon Mac。若要发给其他 Mac 用户安装，还需要单独处理 Apple 签名和公证。

## 打开源码版（macOS）

1. 解压整个“拼好题程序”文件夹，不要只取出启动文件。
2. 双击 **启动拼好题.command**。第一次启动需要联网安装三个排版组件，可能要等几分钟。
3. 浏览器会自动打开拼好题。如果没有自动打开，请把终端显示的本地网址复制到浏览器。
4. 每行输入一道题，例如：

   ```text
   2009年数学一第9题
   2012-17
   2025年数学一第22题
   ```

5. 选择解答题留白大小，点“预览试卷”，确认后点“下载 PDF”。

点击网页底部的“结束程序”，或关闭启动时打开的终端窗口，程序就会停止。再次使用时重新双击启动文件。

## 组卷规则

- 题目按原题型分为选择、填空、解答题，并在新卷中连续编号。2007—2020 年每卷 23 题，2021—2025 年每卷 22 题。
- 新题号使用统一宽度的题号栏并右对齐；题干去除原卷左侧多余空白，保留公式、图形和跨页内容。
- 选择题保留选项和图形；填空题保留原作答横线；解答题添加可选大小的演算留白。
- 卷末列出每题原年份和原题号。重复输入同一道题只收录一次。
- 所有内容只在本机处理；程序不上传你的试卷。原始 PDF 保存在 `sources` 文件夹，不会被改写。

程序只从源 PDF 中选取试题，不生成答案解析；2025 年源 PDF 附带的答案页不会进入组卷。

## 源码与构建

GitHub 仓库只保存源码、测试和题目索引，不包含原始真题 PDF。直接运行源码时，需将对应年份的 PDF 放在 `sources` 文件夹；本地提供的应用和程序压缩包已包含这些文件。

- `pinhaoti/web.py`：本地网页、预览下载和退出。
- `pinhaoti/ui.py`：原生 HTML/CSS 界面，无需前端框架或联网加载资源。
- `pinhaoti/selection.py`：解析年份、题号并按题型排序。
- `pinhaoti/crops.py`：从原卷裁取题目图片。
- `pinhaoti/export.py`：排版 A4 试卷。
- `data/index.json`：预先核对的题目位置。
- `build_index.py`：读取 `cache/ocr.txt` 重建位置索引；需要 `requirements-dev.txt` 中的依赖。
- `build_mac_app.sh`：在 Apple Silicon Mac 上用 PyInstaller 构建 `.app`；先安装 `requirements-build.txt`。
